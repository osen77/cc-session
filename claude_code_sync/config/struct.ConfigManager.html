pub fn config_dir() -> Result<PathBuf>

Get the main configuration directory path following platform conventions:

  • Linux: $XDG_CONFIG_HOME/claude-code-sync or ~/.config/claude-code-sync
  • macOS: ~/Library/Application Support/claude-code-sync
  • Windows: %APPDATA%\claude-code-sync

pub fn sync_repo_lock_path(repo_path: &Path) -> Result<PathBuf>

Get the lock file guarding write access to one sync repository.

The name is derived from the repository path so several repositories never share a lock. It lives in the config dir rather than inside the repository itself, so the lock is available even before the repository is initialized, and never risks being committed.
