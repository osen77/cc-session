Module nav_select 

Source
Expand description

Minimal navigable select menu with level navigation on arrow keys.

inquire’s Select owns Left/Right for its filter-input cursor and exposes no custom keybinding API, so the interactive session manager uses this widget instead: Left goes back one level, Right (or Enter) selects the highlighted option. Key handling lives in the pure NavState so it is testable without a TTY; only NavSelect::prompt touches the terminal.
