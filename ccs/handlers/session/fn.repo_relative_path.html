Compute the path of a session file relative to the sync repo’s projects/ directory, mirroring [crate::sync::push]’s compute_relative_path logic but operating on a SessionSummary instead of a ConversationSession.

Returns None when the session is not under ~/.claude/projects/ (e.g. Codex sessions, which are not synced and have no repo representation).
