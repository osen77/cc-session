Module repo_lock 

Source
Expand description

Inter-process mutual exclusion for the sync repository.

Several entry points write to the same repository — the Stop hook’s push, the SessionStart hook’s pull, the launcher wrapper, manual commands and session deletion. Git does not tolerate concurrent writers: the loser hits index.lock or a non-fast-forward and exits non-zero, which surfaces to the user as a hook failure.

Every writer takes this lock first, so they serialize instead of colliding. The lock is advisory and process-wide, held for the duration of the guard.
