RAII guard for exclusive access to one sync repository.

impl RepoLock

Source

pub(crate) fn acquire(repo_path: &Path) -> Result<RepoLockOutcome>

Take the lock, waiting only when a human is watching.

Non-interactive callers (hooks, wrappers, scripts) must not stall: the Claude Code hook harness kills them after 60s and reports an error, so waiting merely trades one failure for another. They get Busy immediately. Interactive callers typed the command and expect it to run, so they poll up to INTERACTIVE_WAIT.

pub(crate) fn acquire_or_report( repo_path: &Path, operation: &str, verbosity: VerbosityLevel, ) -> Result<Option<Self>>

Take the lock, reporting contention for the caller.

Returns None when the repository is busy — the caller should return success without doing work. A skipped sync is not an error: returning non-zero here is exactly what makes Claude Code report a hook failure, and the next hook will sync anyway.
